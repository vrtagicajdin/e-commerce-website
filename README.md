# E-commerce Website

Responzivna e-commerce web stranica za pregled i kupovinu odjeće. Projekat je izrađen pomoću HTML-a, CSS-a, JavaScripta i Bootstrap-a.

## Stranice

- Početna — pregled ponude i početna stranica (`index.html`)
- Proizvodi — prikaz proizvoda (`products.html`)
- O nama — informacije o projektu (`about.html`)
- Kontakt — kontakt stranica (`contact.html`)
- Prijava — stranica za prijavu (`login.html`)
- Plaćanje — stranica za naplatu (`checkout.html`)

## Korištene tehnologije

- HTML5
- CSS3
- JavaScript
- Bootstrap

## Struktura projekta

```text
e-commerce-website/
├── about.html
├── checkout.html
├── contact.html
├── index.html
├── login.html
├── products.html
├── css/
│   └── style.css
├── images/
